## Overview

VectorCraft is a clean-room, open-source reimplementation of the Adobe Illustrator workflow, written from scratch in pure Rust (`README.md`). It runs natively on macOS, Windows, Linux and FreeBSD and in the browser via WebAssembly (`apps/vectorcraft-web/`). Maturity: **alpha** — the project self-assesses ~88% feature breadth, ~75% depth and ~62% ready for real work; treat percentages as self-assessed and the code as authoritative (the docs still print 348/353 menu items, 89/92 tools and 46/50 effects where the code now has 94 tools and a 118-entry effect catalogue). Source: GitHub `storytold/vectorcraft`. Every user-visible action is a command reachable over MCP, the JSON control channel, the browser API and the CLI, and since v0.24.1 also from JavaScript scripts (`AGENTS.md`; `docs/mcp.md`; `docs/control-protocol.md`). The UI is egui with craft-ui docking; v0.22.0 added document windows and Hindi, and v0.24.1 adds the Script Console, Color Wheel and 3D and Materials panels.

Project rules that bind anyone working in or around the repo: never run, script or copy from Adobe applications (clean-room, `AGENTS.md`); no panics in shipped code (clippy-denied, plus `crates/engine/src/guard.rs`); every bundled asset is attributed in `ASSETS.md`.

### Documents and UI
- Native format `.vectorcraft` (legacy `.drawcraft` still opens): versioned JSON, `VERSION = 4`, down-saves to v1/v2 as `drawcraft`, optional gzip (capped on wasm32), embedded PNG preview, atomic saves, unknown keys from newer versions preserved (`crates/format/src/lib.rs` imports `VERSION` from the craft vectorcraft-format crate; `crates/engine/src/cmd/fileio/save.rs` documents `version: 4`; `docs/mcp.md` › Native files). Save options include `compress`, `version`, `preview`, `precision: 0..9`, `separateArtboards`, `includeLinked`, `embedProfiles` and `pdfCompatible`.
- Multiple documents open as **tabs** in one window, each with **artboards**, layers and sublayers; panels dock on craft-ui's shared docking (floating panels in OS windows, collapse to tabs); workspaces keep layout changes (`crates/ui-egui/src/state.rs`; `crates/ui-egui/src/panel_docking.rs`; `docs/ui-parity.md`). Documents float in their own windows (Window › Arrange › Float in Window, Float All in Windows, Cascade), drag out of the tab strip and back to dock, and open in windows when Open Documents As Tabs is cleared (`crates/ui-egui/src/doc_windows.rs`). `--new-instance` starts a second process; `--safe-mode` starts without plug-ins (`apps/vectorcraft/src/main.rs`).
- **Ruler guides are document objects on their layers** since v0.24.1: `guide.add`, `view.guides.make/release/lock/clear`, `Document::ruler_guides`, and guides move/select/lock like art (`crates/doc/src/guides.rs`; `crates/doc/src/document_guides.rs`; `crates/engine/src/cmd/docmenu.rs`). Artboard guides (center mark / cross hairs / video safe areas / video ruler PAR) remain per-artboard via `artboard.setProps`/`artboard.new`; Distance Guides on Alt/Option hover; a Constrain Angle preference.
- **Guides, artboards and history**: `artboard.rename` and `artboard.switchOrientation` are new commands; `edit.newDocumentFromState {index}` makes a new document from a History-panel row; `document.compare {path, artboard?, background?, threshold?, diffPath?}` renders the artboard at the image's size and returns `rmse`, the differing-pixel count and an optional diff PNG (`crates/engine/src/cmd/edit.rs`).
- Export bytes are reproducible: `SOURCE_DATE_EPOCH` replaces the wall clock in PNG, PDF, EPS, legacy `.ai`, packaged zips and `.vectorcraft` saves; a malformed value is ignored (`crates/doc/src/metadata.rs`).
- 25 saved views list in the View menu with Edit Views… (`crates/ui-egui/src/menus/tests.rs`; `crates/engine/src/cmd/views.rs`).

The Pen tool and `path.join` continue, close and join **compound paths**; `Ctrl+J` joins selected end points; the Join tool connects endpoints near scrub-line ends; Pathfinder Options… (Precision, Remove Redundant Points, Divide/Outline removes unpainted artwork) works.
- Appearance stacks (multiple fills/strokes, per-item effects), transparency, blob/opacity masks, clipping masks, graphic styles, global/spot swatches, gradients (linear/radial/**conic**/freeform, mesh) with Method Classic/Perceptual (OKLab) and Dither (fills only), patterns and recolor (`crates/engine/src/cmd/appearance.rs`, `paint.rs`, `gradient.rs`, `patterncmds.rs`, `recolor.rs`, `opacitymask.rs`). **Conic** gradients sweep their stops once around the centre, clockwise from the vector, with a negative `aspect` mirroring the sweep (`crates/engine/src/cmd/gradient.rs`; `paint.setFill`/`paint.editGradient`).
- Brushes: calligraphic, scatter, art, pattern, bristle with default libraries and expansion to real objects; Window › Brush Libraries, New Brush from the art its options opened with, Art Brush Options' Width can follow pen pressure, Eraser tip Angle/Roundness (`crates/brush/src/lib.rs`; `crates/ui-egui/src/panels/brushes/`).
- Symbols, blends, envelopes, radial/grid/mirror Repeat (Grid Repeat has on-canvas handles), perspective grid, Intertwine, Objects on Path (its Space widget spaces attached objects along the path), 9 graph types with graph designs, Variables/data sets (4 kinds: text, visibility, image, graph) (`crates/engine/src/cmd/graph.rs`, `variablecmds.rs`, `perspgrid.rs`, `intertwine.rs`, `objects_on_path.rs`; `crates/doc/src/variables.rs`). Symbols gained name sorting (`symbol.sortByName`), instance part selection/reset (`symbol.instance.selectPart`, `resetTransform`) and Small/Large List panel views.
- Transform Each reopens on the values it was last confirmed with and has a Copy button; the Transform panel menu's Object Only / Pattern Only / Both / Use Registration Point for Symbol act; unit fields accept a decimal comma; Scribble effect Settings presets. Paste in Place, in Front and in Back put a copy on each selected artboard (`crates/engine/src/cmd/edit.rs`). Pixel-grid work uses `object.setPixelAligned` and Object › Not Aligned to Pixel Grid (`select.object.notAlignedToPixelGrid`; `crates/engine/src/cmd/object/pixelgrid.rs`).

### Type
- Point, area and type-on-a-path type, threading across frames (visible in/out ports, double-click a port to break the thread), character/paragraph styles, OpenType features, vertical type with initial CJK support, Hebrew/Arabic bidirectional layout, Thai/Lao/Khmer/Myanmar word breaking, Touch Type, Hyphenation…/Justification…, Roman Hanging Punctuation, Optical Margin Alignment, No Break, System Layout, Fractional Widths, Snap to Glyph (`crates/text/`; `docs/type-parity.md`).
- **Auto lists**: typing `1. `, `A) ` or `* ` at a paragraph start starts a list; **Convert to Text** turns bullets/numbers into characters; exported PDF list markers are selectable text (`crates/engine/src/cmd/typecmd.rs`).
- **Ruby (ふりがな)**: `type.ruby` sets/removes a reading over a byte range — above/below, aligned, sized, overhanging or squeezed; saved natively, laid out with line growth, drawn and exported in SVG/PDF, and kept through Create Outlines, EPS, EMF/WMF and legacy `.ai`. No UI panel or type-on-a-path ruby yet.
- **Colour fonts**: `sbix`/`CBDT` bitmap emoji, **COLR v0/v1** (`crates/text/src/colr.rs`) and **OpenType SVG glyphs** (`crates/text/src/svg_glyph.rs`) draw and export as vector art; bitmap glyphs survive effects, Expand Appearance and EMF/WMF. Still open: CPAL palette variables, scripts/text inside SVG glyph documents.
- **Dynamic Text** (`type.dynamicText`): sizes type on a path to fill the span between its brackets and sets each line of area type to the frame width, refitting after every edit within 0.1–1296 pt (`crates/engine/src/cmd/typemenu.rs`; `crates/engine/src/cmd/typecmd/block.rs`; `crates/engine/src/tests/dynamic_text.rs`). - **Composite fonts** (`type.compositeFonts.set/list/import/export`): a font per character class (Kanji, Kana, Punctuation, Symbols, Roman, Numerals), each with style, size, baseline and scales; saved with the document and stored in `.vccomposite` files. - **Spell check** (`text.spelling.check/suggest` from craft-proof; `addWord`/`removeWord`/`changeWord`/`dictionary`/`editDictionary`/`ignoreAll`; Auto Spell Check via `edit.autoSpellCheck` and its right-click menu). - Type on a path: joined scripts bend along the path so their joins stay connected; a Direct-Selection drag of an on-path anchor reflows the type. Text placed from `.txt`, `.rtf` and Word `.docx` as area type with formatting (`crates/engine/src/cmd/place/`). `text.glyphAlternates` lists a character's alternate glyphs and `text.setGlyphAlternate` picks one (`crates/engine/src/cmd/textedit.rs`).

### Effects and 3D
- **All 57 Photoshop-style raster filters** ship live and editable, plus **Effect › Effect Gallery…** (`ui.effectGalleryDialog`): six raster submenus, Add to Stack, reorder/remove, per-effect params, live canvas preview, a thumbnail per filter and an in-dialog preview; OK applies the stack as separate appearance effects in one undo step (`crates/effects/src/pixel.rs`; `crates/ui-egui/src/dialogs/effect_gallery.rs`). The gallery does not list the Blur, Pixelate, Sharpen or Video groups (those stay in the Effect menu).
- Illustrator-style effects catalogue: `crates/effects/src/catalog.rs` (`effect_catalog()`, **118** entries = 91 direct + 15 `WARP_STYLES` + 12 `PATHFINDER_EFFECTS`). The last hole closed: **SVG Filters** (`svgFilter.*`, `SVG Filter` effect; 50/50 per `docs/effects-parity.md`).
- Initial 3D plus Classic: live **Revolve, Extrude & Bevel, Inflate, Rotate** and **Extrude & Bevel (Classic)** with caps, bevels, twist/taper, perspective and 1–10 coloured lights (`MAX_LIGHTS = 10`); four lighting presets via `effect.lightingPreset`; faces export as vector art (`crates/three-d/src/lights.rs`; `crates/effects/src/solids/classic.rs`; `docs/three-d.md`). **No materials, shadows or ray tracing**; the Materials tab and `Materials…` entry remain placeholders. ### Files — open / read (implemented)
`document.open` / File › Open reads **46 extensions** — authoritative list `OPEN_EXTS` in `crates/engine/src/cmd/fileio/formats.rs:514`: `.vectorcraft`, `.drawcraft`, `.svg`, `.svgz`, `.pdf`, `.ai`, `.ait`, `.png/.pns`, `.jpg/.jpeg`, `.gif`, `.webp`, `.tif/.tiff`, `.bmp/.dib/.rle`, `.tga/.vda/.icb/.vst`, `.pcx`, `.pxr`, `.jp2/.jpx/.jpf/.j2k/.j2c/.jpc`, `.heic/.heif`, `.jxl`, `.psd/.pdd/.psb`, `.vctemplate`, `.dxf`, `.emf`, `.wmf`, `.eps/.epsf`, `.ps`, `.af`, `.afdesign`, `.afpub`. File › Place reads **50 extensions** — those plus `.txt`, `.rtf`, `.docx`, `.doc` (`PLACE_EXTS`, `:603`; `TEXT_EXTS`/`RTF_EXTS`/`DOCX_EXTS`/`DOC_EXTS`).
- **SVG/SVGZ** — strongest interchange both ways; symbols, patterns, CSS, filters mapped to live effects, Inkscape extensions, multi-page artboards; unsupported filters are named in `warnings`; foreign XML namespaces round-trip (`crates/svg/src/export.rs`; `docs/file-format-parity.md`).
- **PDF and `.ai`** — own reader; PDF opens with layers, editable text, masks, security, overprint; `.ai` reads Illustrator's private editing-data structure (up to 512 MiB on 64-bit) and legacy PostScript-form `.ai` via a PostScript Level 3 interpreter; Illustrator blends import as live blends; a multi-page `.ai` can open a named page (`crates/pdf/`; `crates/eps/src/import/ai/`; `docs/file-format-parity.md`).
- **EPS/PS** — own PostScript L2/L3 interpreter and editing-data reader (`crates/eps/`); `.ps` opens (the file-format summary's "PS missing" row is stale).
- **PSD/PSB** open **with layers** by default: each layer becomes a document layer holding its pixels, with names, visibility, opacity and blend modes; groups become sublayers; layer masks become opacity masks; clipped layers and unsupported blend modes are merged with the layers below. `layers: false` gives the old merged image; hidden layers are left out unless `hiddenLayers`; adjustment layers, layer effects and vector masks are not applied. File › Place still places them as their merged image (`crates/engine/src/cmd/fileio/psdlayers.rs`; `crates/engine/src/cmd/fileio/commands.rs`; `README.md`).
- **HEIC/HEIF** — HEVC-coded still pictures and tile grids, 8–10 bits, with alpha; image sequences and other codings are refused (`crates/engine/src/cmd/fileio/heifread.rs`). **JPEG XL** — first frame, 16-bit/float samples reduced to 8 bits, alpha kept, CMYK refused (`crates/engine/src/cmd/fileio/jxlread.rs`). Both are read-only.
- **Affinity** `.af` (Affinity 3), `.afdesign`, `.afpub` and, by content, `.afphoto` — native **read-only** import; 51 pinned corpus documents (`crates/affinity/README.md`; `docs/affinity-validation.md`).
- **DXF** (R12–2018), **EMF/WMF** (bitmaps share one decoded-pixel budget), rasters incl. TIFF with CCITT Group 3/4 (`crates/cad/`, `crates/metafile/`). **Importer plug-ins** add read-only `plugin.<id>` formats; `document.open {importer, params}` or File › Open With selects one (`crates/engine/src/cmd/fileio/importer.rs`; `docs/plugins.md`). Read `warnings` on every open.

Save As `.ai` writes a **PDF-compatible** file by default (carrying the native document when every artboard is written in order), or **legacy version 7** (`aiVersion: "7"` / `convert --ai-version 7`) which keeps layers, groups, compound paths and editable type, one artboard per file; transparency, live effects and object names don't survive it, and Illustrator's private editing data is never written; `convert` to PDF omits editing data unless `--preserve-editing`.

Extension-driven `document.export` (`export_extensions()`): `.vectorcraft`, `.vctemplate`, `.svg`, `.svgz`, `.pdf` (presets, PDF/A-2b, PDF/X-1a/3/4, layers, marks/bleed, ICC, security, `/DisplayDocTitle`, `longPagesInPoints`), `.ai`, `.eps`, `.dxf` (R12–2018), `.emf`, `.wmf`, `.png`, `.png8` (indexed), `.jpg`, `.webp` (**lossless only** — a lossy request is written lossless with a warning), `.gif`, `.tif`, `.bmp`, `.tga`, `.psd` (**layered**), `.txt`. Exporter plug-ins add their own formats (`plugin.<id>`). Pattern fills/strokes are written as real PDF tiling patterns. Artboard background colours are drawn behind exported art by default (`includeArtboardFill`). Plus Export for Screens / Asset Export (`<filename>` takes the saved document's file name; sizes refuse signs/exponents/non-numeric text), Export Selection, Export As with `rect` page-area rasters, CSS Properties export, Save for Office, Print/Print Tiling and Package (`crates/engine/src/cmd/print.rs`, `css.rs`, `package.rs`, `printtiling.rs`, `crates/engine/src/cmd/fileio/screens.rs`).

### Scripting, automation and extensions
- **JavaScript scripting** — `script.run` runs a `.js`/`.jsx` file (or `source`) against the open documents through the `vc` object: `vc.run(id, params)` executes any command, `vc.document` is a snapshot, `vc.commands` lists what a script may run, `vc.log` writes to the report and Script Console, `vc.args` is the run's JSON args, `vc.api.version/has` describe the API. `$` supplies ExtendScript-ish helpers (`$.write`, `$.writeln`, `$.evalFile`, `$.fileName`, `$.includePath`, `$.engineName`), `alert`/`confirm`/`prompt` open dialogs (answered from `answers` when headless), and `#include`/`//@include` plus `JSINCLUDE` load files. `#targetengine name` keeps globals in a named engine (8 per session, 64 MiB each; not on the web); `script.engines` lists and `script.engine.drop` drops them. A run is one transaction: one "Run Script" undo step per changed document, full rollback on an uncaught error/limit/`script.stop`, while files already written stay written and are named. Limits: 8 MiB source (32 MiB with includes), 1e9 instructions by default (1e11 max), 256 MiB heap (128 MiB on wasm), 2,000,000 host calls, 16 MiB and 1,048,576 entries per bridged value, 2048 console lines. File/Folder objects are **read-only** and confined to the script's folder and automation read roots (`crates/engine/src/cmd/scripts.rs`; `crates/engine/src/script/{mod,console,dollar,dialogs,files,folder,include}.rs`; `crates/js/src/lib.rs`; `docs/mcp.md` › Script engines).
- **Script tooling** — File › Scripts lists `.js`/`.jsx` files from the `Scripts` folder (subfolders as submenus; `script.listInstalled`), Other Script… runs a file after a warning (unless Preferences › General › Show External Script Warning is off) (`ui.runScript`), Window › Script Console shows output/errors/reports (`script.console`, `script.console.clear`, `crates/ui-egui/src/panels/script_console.rs`). **Reference-app scripts are not executed**: `script.check` statically analyses `.jsx`, `.jsxinc` and `.jsxbin` (needs, includes, document-model use, menu commands, problems) and shows a report (`crates/scriptcheck/src/`; `crates/engine/src/cmd/scripts.rs`; `ui.checkScript`).
- **MCP server** (stdio, newline JSON-RPC 2.0): `vectorcraft-cli mcp` — remote backend (default: connect to `127.0.0.1:7979`, fall back to headless) or `--headless`. **33 tools** (`crates/mcp/src/tools/definitions.rs`): `command_list`, `command_run`, `run_command`, `command_batch` (≤256 steps, `atomic`, `$N.path`), `doc_inspect`, `inspect_document`, `ui_inspect`, `inspect_ui`, `ui_screenshot`, `list_commands`, `select_tool`, `pointer_gesture`, `draw_path`, `draw_shape`, `set_paint` (reports how many objects it painted), `press_key`, `type_text`, `answer_dialog` (sets fields of the app's open dialog, then confirms or cancels), `invoke_menu`, `open_panel`, `screenshot`, `open_file`, `save_file`, `export`, `add_text`, `apply_effect`, `pathfinder`, `transform`, `create_graph`, `text_wrap`, `render_preview`, `undo`, `redo`. **8 prompts**, **4 fixed resources** (`document`, `document/json`, `commands`, `command-reference`) **+ 4 URI templates** (`object/{id}`, `command/{id}`, `effect/{id}`, `swatch/{name}`), completions, logging, cancellation and a 2 s busy guard. Caps: 16 MiB lines, 64-message batches, 8 MiB kept step results, 256 MiB app replies. Protocol `2025-06-18`; clients asking for `2026-07-28` also get `resultType: complete`, `ttlMs` and `cacheScope` (`crates/mcp/src/server.rs`; `crates/mcp/src/prompts.rs`; `crates/mcp/src/resources.rs`; `docs/mcp.md`).
- **Control channel** — `vectorcraft --control <port>` listens on `127.0.0.1` only, one JSON request per line. **29 canonical methods (30 accepted strings with the `command` alias)**: `engine.execute`, `engine.commands`, `document.inspect`, `ui.inspect`, `ui.menu.list`/`ui.menu.invoke`, `ui.contextMenu.list`, `ui.tool.select`/`ui.tool.list`, `ui.pointer`, `ui.key`/`ui.text`/`ui.move`/`ui.click`/`ui.drag`/`ui.wheel`, `ui.set`, `ui.dialog.set`/`confirm`/`cancel`, `ui.resize`, `ui.focus`, `ui.screenshot`, `ui.render`, `ui.docking`, `app.open`/`save`/`export`/`quit` (`crates/ui-egui/src/control.rs`; `docs/control-protocol.md`). No authentication — loopback only; 4 MiB request line, 16 connections, 60 s reply wait, 300 s idle. `ui.dialog.set` errors on a field the open dialog does not read. - **Browser API** — the web build exposes **11 calls** as promises on `window.vectorcraft`: `request`, `execute`, `commands`, `docInspect`, `uiInspect`, `screenshot`, `inspect`, `openFile`, `captureDownloads`, `files`, `readFile` (`apps/vectorcraft-web/src/api.rs`; shared `PageApi`).
- **CLI** `vectorcraft-cli` (`apps/vectorcraft-cli/src/main.rs`): `mcp` (`--connect ADDR | --headless`, repeatable `--automation-read-root`/`--automation-write-root`, `--allow-plugin-grants`), `run` (headless batch; `--in FILE`, repeatable `--cmd ID --params JSON`, repeatable `--export FILE`, `--scale`, `--ppi N`, `--allow-plugin-grants`; `--commands FILE|-` reads a JSON array or JSON Lines, 64 MiB/100,000 steps; a step's result is referencable as `$N.path`), `commands` (full catalogue as JSON), `convert IN OUT` (`--scale/--ppi/--artboard/--range/--outline-text/--decimals/--replace-lossy/--editing-data/--preserve-editing/--legacy-name-encoding/--ai-version 7|pdf/--hidden-objects layer|omit|visible/--transparent-images flatten|omit`; refuses to overwrite its input when reading it left things out unless `--replace-lossy`; reports `importWarnings`), `info FILE`, `bench FILE [--size WxH] [--iters N]`, `perf [--paths N] [--deep] [--native-io [--artboards 1..4]]`. - **Plug-ins**: sandboxed WebAssembly modules (ABI v1; API level 2 adds host imports for progress/cancel/log, settings and cache, and command calls) as object **filters**, live **effects**, **importers** (read-only `plugin.<id>` formats) or **exporters** that add formats; up to **256** typed parameters; permissions are granted at install and a heavy budget is opt-in; Safe Mode starts or runs without plug-ins and lists the disabled ones (`crates/plugins/src/manifest.rs`; `crates/plugins/src/permissions.rs`; `docs/plugins.md`; `plugin.safeMode`, `plugin.setEnabled`, `plugin.clearCache`).

## Known limitations and not-implemented

Label guide: repo-admitted gaps (`docs/gaps.md`, ranked G1–G19) are work the app cannot be assigned yet. Where docs and code disagree, code wins; the main disagreements are listed at the end.

- **Stage alpha; not a daily driver yet** (~62% ready for real work; ~65% mainstream, ~75% essentials; ~170–270 h to beta). The ranked gaps: #1 **G1** interaction-fidelity pass over every tool modifier — **never** checked side by side with Illustrator (clean-room forbids it, so "done" means "matches the documentation"); #2 **G9** Illustrator `.ai`/EPS exchange — faithful layer/group structure from the editing data in real files, guides, open speed on large files, and live effects/brushes/symbols as live objects (Illustrator's own editing data is never written); #3 **G10** launch/stability on some Windows 11 and Linux machines; #4 **G8** hardening at scale; #5 **G11** correctness bugs in core tools.
- **3D and Materials**: five effect types (Revolve, Extrude & Bevel, Inflate, Rotate, Extrude & Bevel (Classic)), **no materials, shadows or ray tracing** (~25% depth; painter's algorithm, not solid modelling). The Materials tab and `Materials…` entry are placeholders; Classic Revolve/Rotate/Map Art are absent (`docs/gaps.md` G3; `docs/three-d.md`). **3D import (OBJ/USD/glTF) is not implemented** — those are export-only.
- **Illustrator effects**: the menu count is complete (50/50, including SVG Filters), but depth is not: check `docs/effects-parity.md` before promising a specific option. Apply SVG Filter runs the document's own filters only — no default filter library is bundled.
- **Type still partial**: CJK vertical composition (Mojikumi Settings dialog, custom kinsoku sets), the Check Spelling dialog (engine and Auto Spell Check ship), Retype, CPAL palette variables, custom composite-font character sets/Units/Show Sample, Ruby UI panel and type-on-a-path ruby, and preserving font sizes while scaling a group (`docs/type-parity.md`; `docs/gaps.md` G4).
- **Scripting**: only **ES5.1** JavaScript (plus E4X XML) runs; there is **no reference-app document object model**, so `.jsx` scripts that use `app.activeDocument`/`app.selection` fail even though `script.check` understands them. `#targetengine` is not available on the web; scripts can read but **not write** files, and only inside their own folder/read roots. No AppleScript/VBScript host.
- **Formats not supported at all**: FreeHand, CorelDRAW, DWG (use DXF), PICT, and 3D model import. No Affinity **write**. HEIC/HEIF and JPEG XL are **read-only**; PSD/PSB **place** as merged images (open can keep layers); a `.ps` is read but `document.export` writes no PostScript (print-only output). JPEG 2000, PCX and Pixar are read.
- **MCP limits**: stdio only — no Streamable HTTP/SSE, no `resources/subscribe`, no `sampling/createMessage` or `elicitation/create`; document reads are refused as busy while a long call runs (`docs/mcp.md` › Not implemented).
- **Control port has no authentication** — loopback only; disable it when not in use (`docs/control-protocol.md`).
- **Plug-ins**: ABI v1 core modules (no SIMD/memory64); API level 2 imports need permissions; a plug-in that lists permissions installs only with a grant (or a recorded hash), and `--allow-plugin-grants` should be reserved for plug-ins you trust. Safe Mode is the recovery path when a plug-in stops launch (`docs/plugins.md`).
- **Accessibility** is limited: AccessKit reaches egui widgets, but the canvas/custom panels are not described and nothing is tested with VoiceOver/Narrator/Orca (`docs/gaps.md` G19).
- **Claimed but unverified in this pass**: parity percentages, "done" checklist rows and hours are self-assessments from code against public documentation, never measured against Illustrator; localization catalogues other than Georgian have had no native review; the README's performance figures are project self-reports — measure with `vectorcraft-cli perf` on your machine; macOS pen pressure is implemented but untried on hardware.
- **Doc/code contradictions found at this tag** (code treated as authoritative): (a) `README.md` "What's missing" still lists scripting although `script.run` ships (the missing part is the reference-app DOM); (b) `ROADMAP.md` prints 348/375, 89/92 and 46/50 where `docs/target-app-parity.md` says 353/375 and the code has 94 tools and a 118-entry effect catalogue; (c) `docs/file-format-parity.md` has a summary row saying HEIC/HEIF and PS are missing while its detail rows say they are read, and duplicated summary rows that disagree on the count; (d) `docs/effects-parity.md`'s header says 49/50 while its table says 50/50; (e) `docs/mcp.md` still advertises "Three fixed resources" and "Five prompts" while the code has 4 resources and 8 prompts.

## How to operate

**Launch (macOS):**
```sh
open -a VectorCraft                       # or: open -a VectorCraft --args --control 7979
open -a VectorCraft --args --control 7979 --automation-read-root DIR --automation-write-root DIR
open -a VectorCraft --args --safe-mode --new-instance FILE
```
Desktop flags (`apps/vectorcraft/src/main.rs`; `apps/vectorcraft/src/automation_args.rs`): `--control <port>` (or `VECTORCRAFT_CONTROL_PORT`; a bad port stops the app with an error), repeatable `--automation-read-root <dir>` / `--automation-write-root <dir>` (confine everything an agent reads/writes; `--flag=DIR` also works, and the roots are ignored with a warning when `--control` is absent; `VECTORCRAFT_AUTOMATION_READ_ROOT`/`_WRITE_ROOT` also work), `--in-window-menus` (`VECTORCRAFT_IN_WINDOW_MENUS=1`), `--safe-mode` (no plug-ins load or run; files open in a new window), `--new-instance`, `--version`, `-h/--help`; extra arguments are files to open as tabs. Env: `VECTORCRAFT_CONFIG_DIR` (isolated profile — use this for agent runs), `VECTORCRAFT_NO_PREFS` (no preference reads/writes), `WGPU_POWER_PREF=high|low` / `WGPU_ADAPTER_NAME=<substr>` to pick the GPU (`README.md`).

**The CLI is not inside the `.app` on macOS.** It ships as a separate release asset (`docs/mcp.md` › From an installed release); the bundle holds only the desktop binary, and `vectorcraft-cli` is not installed on a stock launcher install. Build with `cargo build --release -p vectorcraft-cli`, `cargo install --path apps/vectorcraft-cli --locked`, or unzip the asset. Update the app only **between** projects.

**Core workflow concepts:** one document per tab or floating window (`ui.inspect` lists `documents`/`activeDocument`); each document has artboards, layers, objects addressed by stable ids (layer/sublayer objects addressable as `object/{lid}` over MCP); units are points, y down, origin at the first artboard's top-left; a new document is 612 × 792 (`docs/mcp.md`). Selection plus a key object drive most commands; most commands accept explicit `ids`. Artboards carry per-artboard options (background colour, lock, center mark, video safe areas) through `artboard.setProps`; ruler guides are now objects (`guide.add`, `view.guides.*`).

**Open → edit → save/export:** open with File › Open / `app.open` / `open_file` (any `OPEN_EXTS`); save with Save/Save As (`SAVE_FORMATS` above; native saves also take `compress`, `version`, `preview`, `precision: 0..9`, `separateArtboards`) — a document opened from or saved as SVG/PDF keeps that format on Save, and the result's `warnings` say what the format loses. Export with `document.export` (extension or `format` picks the format; PDF/`.ai` write one page per artboard, SVG/SVGZ/EPS one file per chosen artboard, rasters one artboard unless `useArtboards`, with optional `rect` crops). **Always read `warnings`** — on import (EPS preview fallback, unsupported SVG filters, PSD layers merged/left out, Affinity losses…) and on export: they are the loss report.

**Scripts:** put `.js`/`.jsx` files in the `Scripts` folder beside the preferences (File › Scripts lists them, subfolders as submenus; `script.listInstalled` returns the folder and paths) or call `script.run {path}` / `{source}`. In the app a run returns `{running: true, name}` and reports later through `ui.inspect`'s `scriptReport`; headless it returns the full report (`ok`, `changed`, `written`, `log`, `fuelUsed`, `hostCalls`, `slowestCommands`, `console`, `dialogs`). `script.stop` rolls the documents back. Read `script.check`'s report before running an unfamiliar reference-app `.jsx`.

**Keyboard shortcuts:** never guess them. The command catalogue carries each command's shortcut: `vectorcraft-cli commands`, MCP `list_commands`, control `engine.commands` (`crates/ui-egui/src/shortcuts.rs` resolves them). Shortcut sets import/export as `.kys` (`shortcutset` commands).

**Preferences / agent-visible folders (macOS):** `Application Support/VectorCraft/` under the user's home (`ui.json` plus sibling folders Swatches, Graphic Styles, Fonts, Plug-ins, Scripts, PDF Presets, Color Profiles, Data Recovery, logs) (`apps/vectorcraft/src/prefs_dir.rs`; `apps/vectorcraft/src/profile.rs`).

## Working with an AI agent

Prefer the automation surfaces over GUI automation; they are the same engine the UI uses.

- **Live session:** start the app with `--control 7979 [--automation-read-root DIR --automation-write-root DIR]` (each root may repeat), then either talk the control protocol directly or register the MCP bridge: `claude mcp add vectorcraft -- vectorcraft-cli mcp --connect 127.0.0.1:7979` (the bridge forwards each tool call as one control request, so you watch changes live). Add `--safe-mode` when a plug-in is suspect.
- **Headless:** `vectorcraft-cli mcp --headless` or `vectorcraft-cli run --in FILE --cmd … --export OUT`; for long step lists use `run --in FILE --commands steps.json --export OUT` (stdin with `-`). The confinement flags imply `--headless` and refuse `--connect`, so a live app must confine itself with the same flags. `--safe-mode mcp` serves a headless session without plug-ins.
- **Script multi-step work:** `script.run` is better than a long `command_batch` when you need branching, loops or file reads. It is transactional (one undo step per changed document, rollback on error), reports `changed`/`written`/`slowestCommands`, and can be stopped with `script.stop`. Remember it is ES5.1 + E4X, has no Illustrator DOM, and can only read files in the script's folder/read roots. Call `vc.run(id, params)` for commands; get exact ids from `command_list`/`engine.commands`.
- **Inspect before editing:** `doc_inspect {depth: 0}` for the skeleton, then scope with `ids`/`kind`/`limit`/`offset`; `document.find` locates nodes (name/kind/text plus `within`, `intersects`, size, thickness, area and anchor-count filters) and `document.node {id, summary: true}` slices one; read paint with `paint.proxies`; list formats and their options with `document.formats`. For exhaustive parameter docs use `engine.apiReference` or MCP resource `vectorcraft://commands/reference`. On large documents drill — never dump `document.json`.
- **Draw/edit:** `draw_path` (SVG `d` or points), `draw_shape`, `add_text` (point/area/path, `vertical`, `justify`), `set_paint` (reports the painted count), `apply_effect`, `pathfinder`, `transform`, `text_wrap`, `create_graph`, or any command id via `command_run`. `draw_path`/`draw_shape` style and apply effects in the same atomic batch: a refused paint leaves no object and no undo step. Group edits with `command_batch {atomic: true}` so one undo step is recorded. Unknown param keys are rejected with a did-you-mean before anything runs.
- **Drive dialogs headlessly or live with `answer_dialog`**: set the fields of the app's open dialog, then `{"action": "confirm"}` or `{"action": "cancel"}` — the MCP twin of `ui.dialog.set`/`confirm`/`cancel` (which errors on a field the dialog does not read). Script `alert`/`confirm`/`prompt` take `answers` when headless; in the app they wait for the person.
- **Newer commands worth knowing:** `svgFilter.define/import/apply` for SVG-filter effects (no bundled filters — define or import one), `text.spelling.check/suggest` and `edit.autoSpellCheck` for proofing, `type.dynamicText` to fit type to brackets/area frames, `type.compositeFonts.set/import/export` for CJK composite fonts, `assets.add3D` + `assets.set3DFormat` + `assets.export3D` for OBJ/glTF/USDA/USDZ, `document.compare` for image diffs, `edit.newDocumentFromState` to fork a History row, `prefs.export/import` to reproduce a profile, `object.setPixelAligned`/`select.object.notAlignedToPixelGrid` for pixel-grid work, and `actionSet.read` to inspect an `.aia` action set before rebuilding it with the Actions panel or `action.batch`.
- **Prepare inputs for the app:** SVG (cleanest interchange), PDF, EPS, DXF, PNG/JPEG/WebP/TIFF/BMP/Targa/HEIC/HEIF/JPEG XL, PSD/PSB (layers on open, merged on place), CSV/TSV for graphs and Variables data sets, `.rtf`/`.docx`/`.doc` for area type. Fonts: `text.addFontFiles` copies files into the app's Fonts folder; Japanese/Chinese/Arabic faces also come from the optional craft-fonts build input (`README.md`). Reusable logic can ship as a `.wasm` plug-in (ABI v1; API level 2 for host imports/permissions; `docs/plugins.md`) or an importer plug-in for a read-only format.
- **Inspect/repair native files:** `.vectorcraft` is documented, versioned JSON (v4; optional gzip detected by content; unknown keys from newer versions are preserved by save). Prefer `document.save {version: 1|2, compress}` for downgrades over hand-editing; for repairs, open → inspect → command → save, and round-trip verify. `separateArtboards` writes one file per artboard.
- **Verify outputs:** `render_preview`, `ui.render`, `screenshot`; `document.compare {path, artboard, threshold, diffPath}` returns `rmse` and a diff PNG for a reference image; reopen the export (`app.open`, `vectorcraft-cli info`) and diff warnings; `vectorcraft-cli bench`/`perf` for timings. Never trust a silent export.
- **Must NOT:** drive the GUI blind (use control/MCP; `ui.screenshot` needs a presented frame and fails after ~8 s when the screen is locked, the window is minimized or covered; window geometry is not stable across machines); write `.ai` private editing data or Affinity files (not implemented — don't promise them); assume PSD opens with layers when using File › Place (it is merged there); run reference-app `.jsx` scripts that rely on the Illustrator DOM (only `vc`-bridge scripts run); use Adobe apps to create or verify anything (repo clean-room rule; produce test art in-repo instead, `AGENTS.md`).

## Verification protocol

Alpha software: verify by round-trip, never by assumption.

1. **Throwaway round-trip test** before any real job: new document → one edit per feature you plan to use (including ruby, colour-font type, auto lists, conic/perceptual/dithered gradients, a 3D lighting preset, a live imported blend, an SVG filter and a Pathfinder Trap if relevant) → save `.vectorcraft` → export the target format → reopen the export in VectorCraft *and* in the consuming app (browser for SVG, reader for PDF) → compare. Check `warnings` on open **and** export at every step (`convert` returns `importWarnings` beside export warnings). `document.compare` automates the pixel part against a reference PNG.
2. **Master in native, deliver in exchange formats.** Keep the working file as `.vectorcraft` and treat SVG/PDF/EPS/`.ai` as deliverables: formats lose data (PDF-compatible `.ai` carries no Illustrator editing data; legacy v7 loses transparency/effects/names; EPS flattens opacity; DXF approximates gradients/patterns; perceptual/dithered gradients and SVG filters can become images). 3D meshes are a separate asset export, not a document format.
3. **Version and back up per session.** Saves are atomic and failed saves keep the old file, but a format conversion rewrites your project — keep a dated copy of the native file. `convert` refuses to overwrite its input when reading it left things out unless `--replace-lossy`; take that gate seriously.
4. **Pin versions per project.** The launcher auto-updates the app; alpha behaviour changes between releases (this skill covers v0.24.1). Update only between projects, and re-run your round-trip before trusting a pipeline after an update.
5. **Guard automation:** run agent sessions with `--automation-read-root/--automation-write-root` (repeatable; both MCP and app), `VECTORCRAFT_CONFIG_DIR` for an isolated profile, and the control port on loopback only while in use (it has no authentication). Start with `--safe-mode` / `vectorcraft-cli --safe-mode` when plug-ins are untrusted; reserve `--allow-plugin-grants` for plugins you have reviewed.
6. **Trust scripts by transaction, not by promise:** after `script.run`, read `changed`, `written`, `fuelUsed` and the console; a failed run rolls the documents back but leaves files it wrote, named in the report. Run `script.check` on unfamiliar `.jsx` files first.
7. **Reproducible comparisons:** set `SOURCE_DATE_EPOCH` when diffing exported bytes; without it PNG/PDF/EPS/`.ai`/zips/native saves record the wall clock.
