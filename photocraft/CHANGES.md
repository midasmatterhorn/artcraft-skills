- **PDF is now a read format.** `crates/io/src/pdf_import.rs` renders pages through the shared `craft-pdf` (Hayro) crate and opens each page as one raster artboard on a shared canvas: `MAX_PAGES: usize = 16` (`crates/io/src/pdf_import.rs:51`), 300 DPI default, DPI lowered to fit the renderer's side/pixel bounds, `MAX_UNION_PIXELS` 200 M. `.ai` files whose bytes start with `%PDF-` take the same importer (`crates/io/src/lib.rs:571`). Experimental editable text/paths exist only behind the `pdf-editable` feature, which `apps/photocraft-cli` enables (`crates/io/src/pdf_editable.rs`), so `--pdf-editable` is a CLI-only path; the desktop app and MCP open PDFs as raster artboards.
- **`--pdf-dpi`, `--pdf-pages`, `--pdf-editable`** are new `convert` flags (`apps/photocraft-cli/src/args.rs`), and `convert` is where they apply — engine `file.open` passes `ImportOptions::default()`, so the GUI has no PDF page/DPI dialog.
- **`--automation-read-root` is repeatable** (`crates/automation/src/args.rs`, `crates/automation/src/workspace.rs:49` `with_read_roots`): ordered read directories, first existing file wins, only a missing file tries the next root; still exactly one write root. A document opened from a read root outside the write root has no implicit save target and needs an explicit Save As.
- **Bridge authentication gained a challenge handshake** (`crates/automation/src/security.rs:20` `auth.challenge`, `:185` `ServerHandshake`): a client nonce, a server nonce plus HMAC-SHA256 `serverProof`, then `auth {proof}`; the token is never sent. The old single-frame `auth {token}` is still accepted, and `photocraft-cli mcp --bridge` never falls back to it.
- **Raw naming changed in the UI only**: menus and windows say **RAW Develop** / **RAW Develop Filter…** / **RAW Defaults…**, while the command id `filter.cameraRaw`, raw preference ids and PSD/XMP interchange names are stable (`docs/feature-names.md`; `crates/ui-egui/src/menu_catalog.rs`).
- **Corpus totals grew, floors did not**: io corpus 169 -> 170 files (floor 148), psd-tools 308 -> 309 (floor 249), Photoshop oracles 258 (floor 190). `crates/io/tests/it/corpus.rs:151-159`.
- **`docs/gaps.md` lags the code in three places this round**: G10 still lists "Photoshop PDF read" as missing (it landed 2026-11-07 per `docs/file-format-parity.md`), G6 says "0 of 68" tools (the enum has 69), and the header repeats 11 of 183 dead preferences (scorecard: 8 of 199).
