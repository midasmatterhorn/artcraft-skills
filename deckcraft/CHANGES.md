# DeckCraft — round 2026-11-12 changes

Re-pinned: v0.16.0 (`a3e2254d3de32ed1718f156f070b54a34b949b54`) -> v0.18.1 (`7cc73ab1895ed2e30c8afbcada20c70b9ea0a440`, installed `deckcraft 0.18.1`).

## Corrected / re-measured

- **Workspace 24 -> 20 crates.** `crates/opus`, `crates/ogg`, `crates/isobmff` and `crates/matroska` are deleted; the Opus decoder and the Ogg, MP4/MOV and Matroska demuxers now come from craft-libs (`craft-audio`, `craft-media`), pinned at `75895c0321d8cb6e175a42466cba050352b117c5`. The video decoders (`h264`, `hevc`, `vp9`, `av1`) and `bitstream` stay in-tree. `docs/architecture.md` still says "24 crates" — new doc drift, recorded in `evidence.md`.
- **Every automation count re-measured and unchanged at v0.18.1:** 329 engine command ids on 329 `cmd!` sites (234 ordinary / 57 `noundo` / 38 `query`; the id sets diffed between `v0.16.0` and `HEAD` are identical, 0 added and 0 removed), 57 engine shortcuts (56 distinct strings; `Cmd+Shift+V` is still the one collision), 52 UI commands (15 with shortcuts), 12 CLI subcommands, 25 control methods plus the aliases `ui.menu.invoke` and `command`, 25 MCP tools (same names at both tags), 49 transitions, 107 animations (24/17/23/40/3), 28 chart types, 45/9/17 SmartArt, 8 themes x 4 variants, 11 layouts + `Custom`, 183 shape presets, 6 starters, 70 Lucide icons, 40 warps, 48/54 pattern fills, 28/62 cameras with 12 bevels, 12 materials and 15 light rigs, 13 date/time formats, 1 UI language.
- **New web automation surface.** The web build installs `window.deckcraft` (craft-web-api): `request`, `execute`, `commands`, `docInspect`, `uiInspect` and `screenshot`, each a Promise over the same control-channel methods (`apps/deckcraft-web/src/api.rs`; `packaging/web/README.md`). Calls reject after 30 s; the shared crate also caps calls waiting at once at 64 (the craft-libs `web-api` crate, not audited here). The skill now names this as a fourth automation surface, scoped to the page.
- **Validation corrected/tightened.** `shape.adjust` and `shape.quickStyle` now reject a negative or fractional `index` instead of silently using 0/1 (`crates/engine/src/cmd/shape/appearance.rs`); `format.paragraph` now rejects an unknown `align` name instead of silently left-aligning, and accepts `centre` and `justifyLow` as synonyms (`crates/engine/src/cmd/format/paragraph.rs`). `shape.lock` no longer toggles a child twice when its group is also in the same `ids` list (`crates/engine/src/cmd/shape.rs`).
- **PPTX round-trip gains.** `a:scene3d`, `a:sp3d` and `a:flatTx` on a text body and a group's `p:grpSpPr` are kept as raw XML (64 KiB cap, element-name validated on write: `crates/model/src/text.rs`, `crates/pptx/src/read/{dml,shapes}.rs`, `crates/pptx/src/write/{dml,shapes}.rs`). SmartArt whose `dgm:dataModel` has no parent-child `cxn` now keeps its node text in `ptLst` order instead of dropping it (`crates/pptx/src/dgm.rs`). A chart past the presentation budgets is kept as its original part (`Chart.verbatim`) and written back whole rather than dropped (`crates/pptx/src/read/chart.rs`, `crates/pptx/src/write/chart.rs`).
- **Updater and Flatpak (the v0.18.1 headline fix).** A ready update installs at exit (`apps/deckcraft/src/main.rs::on_exit` → `start_pending_update`), and both Flatpak manifests add `--talk-name=org.freedesktop.Flatpak` so the shared updater can inspect and update the installation (`packaging/linux/flatpak/`).
- **New budgets that change behaviour:** presentation-wide chart limits of 4 000 000 points and 256 MiB of chart decode bytes (per chart 1 000 000 points); MCP `batch` and JSON-RPC batches cap at 1 000 entries and 64 MiB of gathered results (`crates/mcp/src/{tools,server}.rs`); the UI holds at most 16 live video decoders, more videos play sound only (`crates/ui-egui/src/media.rs`); the photo-album editor seeds at most 48 items / 32 MiB per picture / 64 MiB total and refuses to replace an album larger than that instead of deleting the rest (`crates/engine/src/cmd/insert/album.rs`).
- **Doc drift refreshed.** `docs/architecture.md` says 320 commands and 24 crates (code: 329 and 20); `docs/mcp.md` does not mention the new batch caps; `docs/control-protocol.md` still says 16 MiB per request line (code: 256 MiB); `docs/animation-parity.md` still says 14 exits (code: 23); `docs/target-app-parity.md` still says 328 commands; `ROADMAP.md` still cites 226; the `format.align` parameter doc still omits `thaiDist`, and `format.paragraph`'s omits its align values entirely.

## Method

- `git diff --shortstat v0.16.0..HEAD` = **121 files changed, +2 939 / −7 950**. The checkout is shallow and squashed at each tag (only `v0.16.0` and `v0.18.1` exist), so the tag-to-tag diff — not a commit list — is the evidence for the delta.
- Command ids and kinds were parsed from every `cmd!(` literal under `crates/engine/src/cmd/` at both tags with the same regex, then set-diffed (0 added, 0 removed). MCP tool names were parsed from `tool(` lines in `crates/mcp/src/tools.rs` at both tags and diffed. The remaining registries were re-read at `HEAD` in the modules named in `evidence.md`; all were byte-identical between the tags (their files are unchanged).
- The installed bundle was inspected read-only: `Info.plist` (version 0.18.1, `ai.storyteller.deckcraft`), a universal x86_64+arm64 Mach-O, Developer ID signed and notarized, `spctl` accepted it. Only `--version` and `--help` were executed; both exit before any window. No GUI, build, test run or commit.
- All 84 repo-relative paths cited by the previous `SKILL.md` and `references/commands-and-formats.md` were re-resolved against this checkout: none is missing. Symbols named in the text were spot-checked (`save_bytes`, `pdf_options`, `cell_param`, `neighbour`, `scale_shapes`, `slides_to_outline`, `write_file`, `UI_COMMANDS`, `start_transition_preview`).
